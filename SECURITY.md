# Security policy

Security reports concerning AeroBlade 2.1.3 may be sent privately to abdelhamid.bouhelal@g.enp.edu.dz. Include the affected version, Windows version, reproduction steps, and impact. Do not include confidential project data unless its disclosure is authorized.

The distributed executables are not Authenticode-signed. Verify the SHA-256 checksum against the checksum published with the release before running the application.
