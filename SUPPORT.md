# Support

For scientific or technical support, contact Dr. Abdelhamid BOUHELAL at abdelhamid.bouhelal@g.enp.edu.dz.

When reporting a reproducible problem, provide:

1. AeroBlade version and Windows version.
2. Exact steps and relevant input values.
3. Expected and observed results.
4. Screenshots or application logs when useful.
5. A minimal project or input file only when redistribution is permitted.

Do not post confidential, proprietary, or personal data in a public issue.
